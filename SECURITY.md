# Security Policy

The supported version is the current `main` branch.

Please report security problems through the repository's
[private vulnerability reporting](https://github.com/Aperturesurvivor/neural-firmware-arithmetic/security/advisories/new)
flow. Do not include credentials, private paths, unpublished data, or other
sensitive material in a public issue.

For research-method errors, replication discrepancies, or claim-boundary
questions that do not involve confidential information, use the public issue
tracker.

Checkpoints and study bundles are serialized artifacts. Only load files from a
source you trust, keep `weights_only=True`, and verify published digests when
they are available.
